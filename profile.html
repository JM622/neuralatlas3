Profile

A local nickname to label your saved work — not a real account.

This is not a real login system. NeuralAtlas is a static site with no server or database, so there's no password, no email verification, and nothing syncs across devices or browsers. This profile is just a name + color saved in this browser's local storage, used to label saved experiments. Clearing your browser data will erase it. If you want real accounts later, that requires adding a backend authentication service (e.g. Firebase Auth or Supabase) — a separate project from this static site.
